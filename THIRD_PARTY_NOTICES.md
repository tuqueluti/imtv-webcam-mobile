# Dependências e materiais

A interface e o protocolo de sinalização foram desenvolvidos para este projeto. Camo, Iriun, VDO.Ninja e OBS-Mobile foram referências de pesquisa; seus drivers e códigos de aplicação não foram incorporados.

Esta edição usa Next.js, React, React DOM, Lucide React, qrcode, Tailwind CSS e @libsql/client. As versões exatas estão em `package.json` e `package-lock.json`. As respectivas licenças acompanham os pacotes instalados e continuam aplicáveis. TypeScript e tipos são dependências de desenvolvimento.

O adaptador de Vercel/Turso é independente da integração da hospedagem anterior; Vinext, conectores ChatGPT e Cloudflare Workers não são dependências desta exportação.

A logo IMTV e os arquivos da família Mont foram fornecidos pelo usuário. Os arquivos web da Mont foram gerados a partir dessas fontes, preservando as informações incorporadas. Não há autorização geral de redistribuição desses materiais para outros projetos neste documento.
